## 我踩过的坑（记得别再犯）

### 1. 整数除法陷阱 —— `03-球体表面积体积.cpp`

```cpp
double b = 4 / 3 * PI * r * r * r;   // ← 错的
```

`4 / 3` 是两个整数相除，C++ 会**丢弃小数部分**，结果是 `1` 而不是 `1.333`，
所以体积少了约 25%。正确写法：

```cpp
double b = 4.0 / 3.0 * PI * r * r * r;   // 至少一个操作数是小数
```

**规律**：以后只要看见整数除整数，先想一想会不会被截断。

### 2. 同一个题目做了两遍

`02` 和 `02b` 是同一道题（交换两个数）。原因是重做的时候**没有覆盖原文件，
而是新建了一个项目**。以后重做练习，建议直接改原文件，或者建一个带日期的文件夹。

## 重要提醒

⚠️ **`.cpp` 文件不能单独拿去编译运行**，它要靠项目里的这些文件才能工作：

- `.sln` —— 解决方案文件
- `.vcxproj` —— 项目配置
- `.vcxproj.filters` —— 文件分组

**如果想重新打开这些程序**，有两个办法：

1. **简单办法**：打开 Visual Studio → 新建一个"空项目" → 把 `.cpp` 内容复制进去 → 编译
   （文件就这么短，复制粘贴最快）
2. **完整办法**：把原来的**整个项目文件夹**一起保留

**可以放心删除的**（这些是垃圾，删了 VS 会自动重建）：
`.vs` 文件夹、`x64` 文件夹、`Debug` / `Release` 文件夹、`packages` 文件夹
